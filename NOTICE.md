## Format sources

The readers were written against public format documentation and public-domain code. Only Unlicense/public-domain
code was consulted for ports; GPL tools (Ohana3DS-Rebirth, Kuriimu, melonDS, DeSmuME, Dolphin's source, Cemu's source) were not read.
Of the sources below, only facts were taken: offsets, field sizes, magic numbers, table layouts. No text and no code was copied.

| Source | License | Used for |

| SPICA by gdkchan, https://github.com/gdkchan/SPICA | Unlicense (public domain) | CGFX structure order and field sizes, PICA command register layouts, the texture format table, the ETC1 block bit layout and the Morton swizzle table, and (banner3ds-scene) the CGFX object layouts: models, shapes, materials, lights, cameras, animation curves and their quantizations. | Cartridge header layouts: Pan Docs (Game Boy), GBATEK (Game Boy Advance), the n64brew wiki (Nintendo 64), the SNESdev wiki (SNES), the NESdev wiki (iNES and NES 2.0), Plutiedev and Sega Retro (Genesis / Mega Drive, 32X), SMS Power (Master System, Game Gear) | Public documentation | The `carts` module: header offsets, field meanings, the fixed logo and check bytes, the checksum rules, byte orders and the SMD interleave. The format only; no text and no code copied. Offsets the documentation did not settle were measured on real files by the maintainer and are not reproduced here. |

The Wii banner module (`wii::banner`) is a Rust port of the maintainer's own Kotlin `wiibanner/` (same owner). The banner renderers (`banner3ds-soft`, `banner3ds-gles`, `banner3ds-scene::draw`) are a Rust port of an earlier Kotlin implementation
by the same author; they add no outside source beyond the rows above. The `ids` module is a Rust port of the same author's earlier Kotlin id readers (so no licence question); the rows above name where
the facts it uses are publicly documented. No third-party code was read or copied for it.

The files in `demo/` carry art from SuperTuxKart's Tux kart (Julian "XGhost" Schönbächler, CC-BY-SA 3.0, https://supertuxkart.net); the folder is licensed CC-BY-SA 3.0, see `demo/CREDITS.md`.

No game data is in this repository, and no Nintendo key or key-derived value: tests build synthetic files in code
(`crates/gamemeta-fixtures`), and the committed fixtures (`fixtures/sample.*`) are generated by
`cargo run -p gamemeta-fixtures --bin write-fixtures fixtures`.
